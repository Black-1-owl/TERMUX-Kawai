# KAWAII-TERMUX

A cute and anime-inspired terminal theme for Termux that makes your command line experience more kawaii!

## Features

- 🦉 Animated owl mascot
- 🎀 Random kawaii messages
- 🌤 Weather display (anime style)
- 🈺 Japanese word of the day
- 🦄 Emoji particles
- 📁 Cute system info
- 🎨 Pastel-colored prompt
- 🎵 Notification sounds
- 🎀 Useful aliases

## Installation

```bash
git clone https://github.com/Black-1-owl/TERMUX-Kawai.git
cd TERMUX-Kawai
chmod +x install.sh
./install.sh
source ~/.bashrc
