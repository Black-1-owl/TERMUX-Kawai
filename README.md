📥 Installation

🔧 1. Install required packages

Run this in Termux:

pkg update
pkg install curl git neofetch cmatrix util-linux
pip install lolcat


---

🌸 2. Clone the repository

git clone https://github.com/Black-1-owl/TERMUX-KAWAI
cd TERMUX-KAWAI


---

🎀 3. Install Kawaii Mode

Just run:

bash kawaii-install

This will:

Copy the kawaii script to your home

Add it automatically to .bashrc

Enable all kawaii aliases

Apply the cute theme instantly ✨

🦉 Kawaii Commands (Aliases)

Command	Description

senpai-help	Show all kawaii commands

pls	sudo (kawaii edition)
oops	cute typo warning
g-status	git status
g-commit "msg"	git commit
g-push	cute deploy message

🧩 Customization

You can edit kawaii settings inside:

~/.kawaii-shell

You can change:

✔ Messages
✔ Weather style
✔ Colors
✔ Prompt icons
✔ Owl animation
✔ Sound behavior


---

❣️ Uninstalling

If you want to remove kawaii mode:

bash uninstall-kawaii
